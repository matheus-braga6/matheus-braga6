## 🚀 About Me
I'm a frontend developer from Brazil focused on React, Next.js and TypeScript. Throughout my career, I've built and maintained headless e-commerce stores (PWAs) and admin dashboards, working with Vue.js, Nuxt.js, TypeScript and vanilla JavaScript, with a focus on web performance and reusable components. Before tech, I spent 12 years in music, including seven running my own music school.
